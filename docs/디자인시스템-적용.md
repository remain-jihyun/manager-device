### 공유하는 것 / 하지 않는 것

- **공유**: primary green `#0D5611` · 서체 **Pretendard** · 오류색 `#C91B1B` 계열.
- **비공유**: 컨트롤 높이, 라운드 체계, 타입 스케일, 컴포넌트 규격.
  - 앱: 카드 12 / 컨트롤 10 / 소형 8·6·4
  - 관리 웹: 카드 12 / 컨트롤 8 / 모달 20, 컨트롤 기본 높이 **40px**
  - 현장 단말: 1920 기준 원본을 `--ds-scale` 로 축소해 사용

관리 웹 컴포넌트를 앱으로, 앱 컴포넌트를 관리 웹으로 **그대로 옮기지 않는다.**
공통으로 쓰고 싶은 규격이 생기면 각 폼팩터 Figma 에 먼저 반영한 뒤 각자 구현한다.

### 공통 작업 규칙

1. 값 변경은 **Figma → 토큰 파일 → 화면** 순서. 코드에서 색을 먼저 만들지 않는다.
2. 디자인 적용 작업은 **스타일만** 바꾼다. 로직·데이터·API 를 함께 고치지 않는다.
3. 완료 보고 전 브라우저 실측(`getComputedStyle`·`getBoundingClientRect`)으로 Figma 값과 대조한다.
